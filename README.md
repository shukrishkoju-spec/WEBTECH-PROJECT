# Pathbyte Digital: IT Services Website

A simple responsive multi-page student project for a fictional IT and digital services company.

## Pages
- `index.html`: hero, featured services, why choose us.
- `services.html`: list of services with starting prices.
- `about.html`: short company story.
- `contact.html`: enquiry form validated in the browser.

## Structure
- `css/style.css`: all styling, with Flexbox, Grid and a mobile breakpoint.
- `js/script.js`: mobile menu and form validation.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages
1. Create a public repository, e.g. `pathbyte-digital`.
2. Upload the files so `index.html` is at the root, keeping the `css/` and `js/` folders.
3. Settings, then Pages, then Deploy from a branch, `main`, `/(root)`, Save.
4. Open `https://USERNAME.github.io/pathbyte-digital/` when the build finishes.

## Notes
- Company name, prices and contact details are sample content.
- The form does not send or store anything.
